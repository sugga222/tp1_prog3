🚀 GUÍA DEPLOY EN RENDER.COM - PASO A PASO

═══════════════════════════════════════════════════════════════

PASO 1: CREAR CUENTA EN RENDER
═══════════════════════════════════════════════════════════════

1. Abre https://render.com
2. Haz click en "Sign Up" (arriba a la derecha)
3. Elige "Sign up with GitHub" (así es más fácil)
4. Autoriza a Render a acceder a tu GitHub
5. Confirma tu email

✅ Listo, tienes cuenta en Render


PASO 2: HACER COMMIT INICIAL EN MAIN (IMPORTANTE)
═══════════════════════════════════════════════════════════════

Antes de configurar Render, asegúrate de que todo está en main:

```bash
# 1. Ver rama actual
git branch

# 2. Si estás en dev, cambia a main
git checkout main

# 3. Agregar todos los cambios
git add .

# 4. Commit con mensaje descriptivo
git commit -m "feat(backend): API REST TP3 lista para deploy

- Endpoints GET/POST implementados
- 14 servicios disponibles
- Validaciones completas
- Tests automatizados
- README documentado"

# 5. Push a GitHub
git push origin main

# 6. Verificar que los cambios llegaron a GitHub
# Abre tu repositorio en GitHub y confirma que main está actualizado
```

⏰ Espera 1-2 minutos a que GitHub procese los cambios


PASO 3: CREAR WEB SERVICE EN RENDER
═══════════════════════════════════════════════════════════════

1. En render.com, haz click en "New +" (esquina superior derecha)
2. Selecciona "Web Service"
3. Elige "Deploy an existing project from a Git repository"
4. Si no aparece tu repositorio, haz click en "Configure account"
5. Selecciona tu repositorio: tp1_prog3
6. Haz click en "Connect"

✅ GitHub está conectado


PASO 4: CONFIGURAR EL WEB SERVICE
═══════════════════════════════════════════════════════════════

En la siguiente pantalla, completa:

📝 Nombre:
   tp1-prog3-api
   (o el nombre que prefieras)

📝 Environment:
   Node
   (debe estar seleccionado automáticamente)

📝 Region:
   Ohio (u otra disponible, NO es crítica)

📝 Build Command:
   npm install
   (Render ejecutará esto para instalar dependencias)

📝 Start Command:
   npm start
   (Render ejecutará esto para iniciar la API)

⚙️ Plan:
   Free (el gratuito funciona bien para este TP)

📝 Auto Deploy:
   ✓ Sí (Deploy automático cuando pusheés a main)


PASO 5: AGREGAR VARIABLES DE ENTORNO
═══════════════════════════════════════════════════════════════

Scroll down hasta "Environment Variables"

Haz click en "Add Environment Variable"

Agrega SOLO esto (es opcional, pero recomendado):

KEY:     NODE_ENV
VALUE:   production

KEY:     PORT
VALUE:   (déjalo en blanco - Render lo asigna automáticamente)

⚠️ IMPORTANTE: NO AGREGUES variables sensibles (passwords, tokens, etc.)


PASO 6: INICIAR DEPLOY
═══════════════════════════════════════════════════════════════

1. Haz scroll hasta abajo
2. Haz click en "Create Web Service"
3. Verás una pantalla con "Building..."
4. Espera a que termine (puede tomar 2-5 minutos)

Observa los logs:
- "Building..." → npm install
- "Building..." → npm start
- "=== Service started" → ¡Éxito!

❌ Si ves errores:
- Lee el mensaje de error en los logs
- Los errores más comunes son:
  * Sintaxis en server.js
  * Dependencias faltantes en package.json
  * Puerto ocupado (pero Render lo maneja)

TROUBLESHOOTING (PROBLEMAS COMUNES)
═══════════════════════════════════════════════════════════════

❌ Problema: "Build Failed"
✅ Solución:
   - Verifica que package.json esté correcto
   - Verifica que server.js esté en la raíz
   - Mira los logs de error

❌ Problema: "Service crashed"
✅ Solución:
   - Probablemente hay un error en server.js o un controller
   - Revisa los logs
   - Arregla el error locally y haz git push a main
   - Render lo despliega automáticamente

❌ Problema: "Port already in use"
✅ Solución:
   - No es problema en Render (maneja puertos automáticamente)
   - Puede ser problema local: reinicia "npm run dev"

❌ Problema: Lentitud en primer request
✅ Solución:
   - Es normal en plans gratuitos
   - Render pone en hibernación services inactivos
   - Primer request despierta el servidor (~30 segundos)


NOTAS IMPORTANTES
═══════════════════════════════════════════════════════════════

⚠️ Plan Gratuito de Render:
   - Puedes tener 1 servicio activo
   - Se pone en hibernación si no recibe requests
   - Primer request después de hibernación tarda más
   - Es GRATIS ✓

⚠️ Auto Deploy:
   - Render despliega automáticamente cuando pusheás a main
   - Si cambias en dev y no haces push, no se actualiza
   - Siempre: commit → push → Render deploy

⚠️ Base de Datos JSON:
   - Los datos en usuarios.json se pierden si no regeneran
   - Para producción real, usarías MongoDB o PostgreSQL
   - Para este TP, está bien
